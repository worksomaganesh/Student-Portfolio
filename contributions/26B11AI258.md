## Three Git Commands I Learned

1. `git status` — shows which files are changed, staged, or untracked in the working directory.
2. `git add <file>` — stages a selected file's changes so they can be included in the next commit.
3. `git commit -m "message"` — records the staged changes as a commit in the local Git repository.

## Purpose of GitHub

GitHub hosts Git repositories online so developers can share code, keep projects accessible, review changes, and collaborate with others.

## One Benefit of Branches

A branch lets a developer work on a feature or documentation change separately from the main branch, making the work easier to review before it is merged.
